## 🚀 Featured project: Sistema-ERP

A commercial ERP for SMEs, built from scratch in **PHP 8 + MySQL** (custom MVC, no framework). Its heart is **real-time inventory**: the owner always knows what's in stock, what's running out, and what sold.

**Modules:** purchasing, sales, point of sale (POS), inventory, fiscal invoicing, scale-ticket reading.

**Engineering highlights:**
- 🧪 Automated testing with **PHPUnit** + **GitHub Actions** CI (hundreds of checks: money arithmetic, tax codes, fiscal states)
- 🖨️ **Fiscal printer connector** (Node.js): implements the HKA80 protocol frame-by-frame, verified against the manufacturer's manual
- ⚖️ **Scale integration**: parses scale-printed barcodes/QR into weighed POS lines (DIBAL logic, PLU + weight)
- 🖥️ **Desktop client** (Electron + React + TypeScript): bundles its own PHP + MariaDB runtime — runs the real ERP offline, no XAMPP needed, with ESC/POS receipt printing
- 🏪 Butcher-shop workflows: scale tickets, fiscal printing, product labeling
